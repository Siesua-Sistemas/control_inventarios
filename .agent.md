  - **Infraestructura:** Docker, Docker Compose, Nginx, Redis

  ## Reglas Obligatorias
  1. **Arquitectura limpia:** Clean Architecture, separación por capas, modularización, SOLID, código desacoplado.
  2. **Frontend y Backend separados:** Prohibido mezclar lógica o templates. FastAPI solo como API REST. Next.js solo frontend.
  3. **Backend API REST:** JWT Auth, Swagger/OpenAPI, versionado, middlewares, validaciones, manejo de errores.
  4. **Estructura de carpetas obligatoria** para backend y frontend (ver detalles en la descripción del sistema).
  5. **Base de datos PostgreSQL:** Relaciones, índices, migraciones Alembic, UUID, soft delete, auditoría.
  6. **Docker obligatorio:** Servicios separados, volúmenes persistentes, redes internas, variables de entorno, reinicio automático.
  7. **Nginx:** Reverse proxy, SSL, rutas frontend/backend, compresión, seguridad básica.
  8. **Redis:** Caché, colas, sesiones, tareas background.
  9. **Tareas background:** PDF, QR, reportes, correos, alertas (Celery o RQ).
  10. **Almacenamiento de archivos:** Usar /storage, nunca dentro del contenedor.
  11. **Seguridad:** bcrypt, JWT, RBAC, rate limiting, CORS, validación y sanitización de input.
  12. **Variables de entorno:** Nunca hardcodear secretos ni credenciales.
  13. **Logging y auditoría:** Registrar login, logout, errores, asignaciones, modificaciones, mantenimientos, eliminaciones.
  14. **Escalabilidad y preparación futura:** Pensar en crecimiento, app móvil, integraciones, firma digital, tickets IT, WhatsApp, etc.
